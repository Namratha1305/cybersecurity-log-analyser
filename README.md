# Cybersecurity Log Analyzer

This project analyzes system login logs to detect suspicious activity.

## Features
- Parses log files to extract IP and login status
- Counts failed and successful login attempts
- Detects suspicious IPs based on threshold
- Generates structured security report

## Tech Used
- Python

Built as part of my cybersecurity learning journey to understand real-world log analysis and threat detection.
